Fenêtre — bureau BTC 5 min, sur ton Mac

1. Dézippe cette archive.
2. Ouvre le Terminal DANS le dossier dézippé (pas dans ta maison).
   cd chemin/vers/fenetre
3. Installe, une fois :
   npm install
4. Lance l'interface :
   npm run dev
5. Ouvre http://127.0.0.1:8080

Tu verras le même bureau que l'aperçu. Papier par défaut.
Pour l'argent réel : bouton Réel, colle la clé, coche le consentement, puis Armer.
La clé reste dans cet onglet. Elle n'est pas écrite sur le disque.

Le bot sans fenêtre, dans le même dossier :
   export POLY_KEY_FILE=$HOME/.config/fenetre.key
   npm run bot

Il faut Node.js 22 ou plus récent.

Le journal (aucun ordre, aucune clé), dans le même dossier :
   npm run journal
Laisse-le tourner au moins 2 jours (ordinateur allumé, sans veille).
Il écrit data/journal/observations.csv et data/journal/resultats.jsonl.
Pour lire le verdict, dans un autre Terminal :
   npm run journal:score

Le modèle appris (élan du BTC + carnet Polymarket), une fois le journal bien rempli :
   npm run journal:train
Il s'entraîne sur les fenêtres passées et se teste sur celles qu'il n'a jamais vues.
Il ne vaut quelque chose que s'il dit « bat le marché sur des fenêtres jamais vues ».

Le backtest des stratégies (Normal, Inversé, Stop, Double, martingale, nouvelles idées) :
   npm run journal:strategies

Le suivi papier 24 h/24 (journal + toutes les stratégies en direct, aucun ordre réel) :
   npm run paper
Sur le VPS, pour qu'il tourne en permanence :
   pm2 start npm --name fenetre-papier -- run paper
Le tableau des scores est dans data/journal/papier.json.

Le teneur de marché en papier (ordres limites simulés sur Up et Down, aucun ordre réel) :
   npm run maker
Sur le VPS :
   pm2 start npm --name fenetre-maker -- run maker
   pm2 save
Résultats par fenêtre dans data/maker/resultats.jsonl.
Réglages (facultatifs) : MAKER_SIZE (parts par ordre, 10), MAKER_IMBALANCE (déséquilibre max, 10),
MAKER_MAX_SIDE (parts max par côté et par fenêtre, 100), MAKER_STOP (arrêt avant la fin, 45 s).

La ferme de stratégies (aucun ordre, aucune clé) :
   npm run ferme
Elle part des stratégies déjà testées, en fait pousser des variantes sur le
début du journal, puis juge les meilleures sur la fin du journal — des
fenêtres qu'elles n'ont jamais vues — contre le même jeu à pile ou face.
Seules celles qui battent le hasard, après correction pour le nombre
d'essais, sont promues : le suivi papier (npm run paper) les ajoute alors
tout seul à son tableau, sous le nom « Ferme · … ». Jamais au bot réel.
Sur le VPS, une récolte toutes les 6 h :
   pm2 start npm --name fenetre-ferme -- run ferme -- --boucle 6
   pm2 save
Résultats dans data/ferme/ferme.json (lu par le vaisseau mère).
Il faut un journal d'au moins 100 fenêtres ; le verdict n'a de poids
qu'avec plusieurs milliers (quelques semaines de journal).

L'IA (arbres de décision combinés + réseau de neurones, aucun ordre, aucune clé) :
   npm run ia
Elle apprend sur le journal (cours du BTC + carnet Polymarket) en partant du
prix du marché, puis elle est jugée sur des fenêtres qu'elle n'a jamais vues :
erreur de prédiction face au marché, et trading simulé frais compris
(exécution immédiate et 15 s plus tard). Verdict définitif à 5000 fenêtres.
Sur le VPS, réentraînée toutes les 6 h (IA_HEURES pour changer) :
   pm2 start npm --name fenetre-ia -- run ia -- --boucle
   pm2 save
Résultat dans data/journal/ia.json, affiché dans la page (partie « IA »).
Il faut au moins 300 fenêtres complètes dans le journal.

L'interface sur le VPS, ouverte depuis le vaisseau mère (bot.ton-domaine) :
   pm2 start npm --name fenetre-ui -- run ui
   pm2 save
« npm run ui » n'écoute que sur le VPS lui-même (127.0.0.1:8080) : seul le
tunnel Cloudflare la joint, derrière la porte Access. Son adresse doit être
déclarée à Vite (sinon il répond « host not allowed ») :
   __VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS=bot.ton-domaine pm2 start npm --name fenetre-ui -- run ui
Mode d'emploi complet : vaisseau mère, guide du serveur, étape 16.
